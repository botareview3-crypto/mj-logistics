# public/ — Static assets

## Video scroll section

The landing-page scroll-expand video section looks for:

  /public/hero-video.mp4

Drop any `.mp4` video here with that exact filename and it will be picked
up automatically.  Recommended specs:

- Resolution:  1920 × 1080 or 3840 × 2160
- Duration:    30–90 seconds (it loops)
- Codec:       H.264 (mp4) for best browser support
- File size:   Keep under 15 MB for fast loading

Optional poster (still frame shown before playback):

  /public/hero-video-poster.jpg

If that file is missing the section falls back to the existing ship image
(aerial-view-container-cargo-ship-sea.jpg).
